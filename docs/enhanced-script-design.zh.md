# 增强脚本原设计复核

本次对照公众号“实验语音学与praat软件”安装包中的 88 份 `.cab` 脚本文本及词频脚本，检查修改版随附的 91 份增强脚本。`by`、`bz` 为本版补充实现。此处记录静态逐份复核的处理原则；实际执行范围见自动回归脚本，录像、音量等设备功能仍需实机验证。

## 分隔符格式化与写回

19 份原脚本在读取测量文本前，先把全部空格转为制表符，反复合并连续制表符并移除空行，然后写回所选文件。目的是让手工整理、复制粘贴或不同测量流程产生的空格分隔数据成为一致的表格文本，这一步恢复保留。

按用户确认，已有制表符的字段内空格也视为分隔符；连续分隔符代表同一个分隔位置，不保留空单元格。含空格的文件名或自由文本不能作为一个字段留在这种测量表中。格式化保留行顺序、表头、重复表头和数值字面值，不做排序、平均、删异常值或插入表头。读取后的分析对象仍按对应脚本处理。

格式发生变化才写回，先在输入目录保存原始字节备份 `.before-tabs.bak`；同名备份存在则增加编号。备份失败时终止，不回退到其他目录。再次处理已经规范的文本不会追加备份。备份保留原始编码，格式化后的文本使用 UTF-8。原生 Praat Table 文本／二进制文件不执行这个步骤。分析输出仍默认进入便携 `data`。

## 保留的特殊操作及其用意

- `c`、`l`：只把基频采样点用于 T 值归一化；`l` 还利用时长确定横轴。旧脚本将被误读成表头的首条数据插回，意图是保留首条测量记录；本版正确读取无表头文本，因此不再重复插入。重复表头仍从分析对象中剔除，源文本不因此删行。
- `r`：按句／短语及音节分组，采用 50 Hz 或 64 Hz 参考半音进行起伏度计算，保留矩形范围绘图选项。换算使用等价的 `12 * log2(Hz / 参考Hz)`。绘制时仅合并本次对象，避免把用户其他对象误合入。
- `af`、`ar`、`d`、`i`、`u`、`bb`、`cd`、`cg`：保留采样列选择、分组、平均、归一化和图形输出流程。非数值或异常值的处理由各脚本原有条件决定，不由格式化步骤代替。
- `ay`：保留按选项删除 undefined、离群值或极端值所在行的设计，这些修改发生在分析对象中；`az`、`ba`、`be` 保留相应统计流程。
- `as`：声、韵、调排序、编号和同音字聚合用于整理同音字表，保留。`aq`、`di`、`dj` 中音韵归类、平仄映射、入声韵尾及不同学者拟音转换也继续保留。
- `da`、`db`、`dc`：按测量表中的起止点写入辅音、元音或声调 TextGrid 标注是功能本身，保留；默认可写回用户所选输入目录，也可另存便携 `data`，不覆盖输入音频。
- `m`、`n`：清空 `vowel.txt`、`tone.txt` 用于开始新一批测量，保留；作用范围是便携 `data` 中对应结果文件。
- `dr`：筛掉其他字符后覆盖原文会改变内容，而非仅规范格式。根据用户确认，继续另存筛选结果。
- `y`、`z`：旧流程暂把输入媒体改名为 `video`，用于迁就批处理固定文件名；跨平台实现直接传入原路径，因此保留提取／去音轨功能，不需要再改名原文件。
- `j`：原脚本有基频参数、参考刻度和选区语调图，保留这些用途；修复旧参数形式并通过当前 API 输出曲线、数值及可选 TextGrid 标注。
- 媒体、设备、外部程序菜单保留相应用途，Windows 批处理／命令拼接改为配套跨平台工具。平台之间的设备名称和可用工具并不完全相同。
