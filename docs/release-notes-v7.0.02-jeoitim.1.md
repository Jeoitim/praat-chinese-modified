# Praat 修改版 v7.0.02-jeoitim.1

基于 KasumiKitsune/praat-simplified-chinese 的 modern 分支，Praat 基础版本为 7.0.02。本项目提供 Windows x64、Linux x64 与 macOS 通用应用的完整资源包构建。正式发布的平台与验证记录以实际附件和构建结果为准。

## 修改内容

- 保留现代界面、右键菜单、播放器、快捷按钮和汉化帮助手册。
- 加入贝先明、向柠的汉化及自定义内容，来源为公众号“实验语音学与praat软件”提供的源码和安装包；统一术语并补齐常用提示翻译。
- 将公众号参考安装包原先部署到 `C:\scrpt` 的内置脚本改为从程序资源目录加载；默认分析数据使用独立配置目录。
- 修复菜单分组与关于页自动关闭问题，按组件完整署名作者，并采用上游原图标和中文标语。
- 处理 Windows 高 DPI 清单冲突，随程序私有加载国际音标字体。

## 使用方法

Windows 运行 PraatChineseModified.exe，Linux 运行 PraatChineseModified，macOS 打开完整 .app。保留随包资源，不需要旧 setup.exe。Python、FFmpeg 及设备要求见 docs/cross-platform.zh.md。

## 验证与限制

Windows x64 构建、旧数值命令兼容、音频读写与分析、常见提示汉化已通过检查。全部 91 份脚本通过平台依赖及控制结构检查；新增文本处理、图像导出及含中文空格路径的媒体转换通过样本验证。全部 91 份脚本通过平台依赖及控制结构检查；新增文本处理、图像导出及含中文空格路径的媒体转换通过样本验证。部分 GUI 和手册功能已实际检查；需要设备或特定素材的全部旧脚本尚未逐项验证。发布前应补充维护者自己的常用素材测试记录。
