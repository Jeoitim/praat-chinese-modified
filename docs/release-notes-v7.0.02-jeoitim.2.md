# Praat 修改版 v7.0.02-jeoitim.2

本次为脚本兼容性与界面修复版本，继续基于 KasumiKitsune/praat-simplified-chinese 的 `modern` 分支，Praat 核心版本为 7.0.02。提供 Windows x64、Linux x64 和 macOS arm64/x86_64 通用应用的完整资源包。

## 修改内容

- 修复声调相对、绝对时长统计与画图的表格读取和列名问题，保留无表头测量文件的首行数据；分析表读取支持文本和原生 Table，不再改写输入测量文本。
- 修复起伏度统计中失效的半音函数，明确使用 50 Hz、64 Hz 参考频率；适配语调绘图的参数和命令，支持 Hz、半音及 TextGrid 标注，并保存图形与数值表。
- 修复按指定列统计的图表保存名称、元音散点图等表单的布尔默认值，以及部分脚本将正常完成报告为错误的问题。
- 基频、幅度积等测量结果默认保存到程序旁的 `data`，配置保存到同级 `settings`；macOS 使用 `.app` 所在目录。本进程及配套 Python 工具的临时文件、缓存使用 `data/.tmp`、`data/.cache`，不回退到用户配置目录。
- 自动标注可选择写回用户指定的数据目录，或另存到 `data`；修复失效变量及路径处理，保留跨平台使用方式。
- 修复脚本说明行遮挡下一行复选框等控件的问题，普通参数窗与暂停窗共用完整的说明行高度，调整尺寸后保持一致布局。
- 91 份增强脚本顶部标明 jeoitim 的修改或补充实现，保留原作者署名；README 分别说明增强脚本改进和对上游实现的调整。修复优先放在脚本及独立兼容模块，保留上游声学分析算法。

## 下载与使用

| 附件 | 用途 |
| :--- | :--- |
| Windows-x64.zip | 完整解压后运行 PraatChineseModified.exe，保留 assets 和辅助工具 |
| Linux-x64.tar.gz | 在 Ubuntu 24.04 构建；运行 PraatChineseModified，目标系统需兼容的 GTK 3、音频库和 C++ 运行库 |
| macOS-universal.zip | 解压后打开完整 .app，包含 arm64 与 x86_64 架构 |
| source.zip | 与此 tag 对应的完整源码及资源 |
| SHA256SUMS.txt | 附件 SHA-256 校验值 |

请将完整运行包放在可写目录。默认配置与分析结果分别保存在程序旁的 `settings`、`data`；macOS 保存在 `.app` 所在目录，不写入应用包。目录不可写时会提示错误；可通过 `--pref-dir=<目录>` 显式指定其他配置位置，导出结果也可保存在用户选定的位置。

从上一版升级时，旧配置和结果不会自动迁移。需要继续使用的数据可手动复制到新包旁的 `data`；升级和替换程序时请保留已有的 `data`、`settings`。

Python、FFmpeg、录音录像设备和字体要求见随包跨平台指南。基础语音分析不需要 Python。Windows 保留原安装包的独立辅助 EXE；相关菜单在其他平台采用 Python、系统音量工具及 FFmpeg 等替代实现，界面与设备支持不完全相同。

## 验证与已知限制

三平台在此发布 tag 上重新构建并运行测试。全部 91 份脚本通过平台依赖、修改署名和控制结构检查；兼容数值、音频读写、基频分析、字符提取、字频、音韵条件检索、PNG/PDF 导出及中文空格路径的媒体转换通过样本验证。

新增回归覆盖声调相对与绝对时长绘图、50/64 Hz 起伏度、语调两种标度及 TextGrid、按列统计的三幅图形、自动标注的两种保存位置，以及频带能量、共振峰、塞音、离群值和描述性统计等 11 项额外流程。Windows 另验证实际编辑器中的基频、幅度积保存和便携配置；用实际字调、语调数据核对输入文件在分析前后未被改动，并检查普通参数窗、暂停窗的控件显示。

- 自动检查和样本回归不等于每份脚本的每种语料、交互或设备分支都已验证。
- 麦克风、摄像头、系统回环音源和屏幕录制尚未逐设备验证。Linux 原生 Wayland 屏幕捕获需使用系统录屏工具；macOS 系统声音需相应回环音频设备。
- macOS 包为临时签名，尚未使用 Developer ID 签名和公证。Windows 程序未附带发行者代码签名。
- 旧 H/Bei 命令的兼容实现及差异见 THIRD_PARTY_NOTICES.md；本版本没有替换上游声学分析算法。
